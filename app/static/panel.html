    🔗 Integraciones: webhooks para tu CRM

    Cada lead, compra, reembolso o carrito abandonado se envia como un contacto a las URLs que configures (por ejemplo, el webhook de n8n que lo pasa a HubSpot, Pipedrive, Brevo o GoHighLevel). Va firmado, se reintenta si el CRM falla y queda registrado abajo.

    📈 Meta Conversions API

    Tu servidor envia el Lead y la Compra directamente a Meta, aunque el navegador bloquee el pixel (adblock, iOS). El pixel y el servidor comparten el mismo ID de evento, asi Meta no los cuenta dos veces. Los datos personales viajan cifrados (SHA-256).
    Con el codigo de prueba, los eventos aparecen en vivo en Administrador de eventos → Probar eventos. Borralo cuando termines de probar.
